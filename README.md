# 活动降幅助手（Activity Discount Helper）

一款用于电商活动提报的 Windows 桌面工具。框选屏幕上的商品当前价格，输入目标到手价，即可反算需要填写的活动降幅；同时支持满减券计算。

## 下载

无需安装 Python，也无需配置 OCR。前往 [Releases](https://github.com/Bringt-C/activity-discount-helper/releases/latest) 下载 `活动降幅助手.exe`，双击即可使用。

> 支持 Windows 10/11 64 位系统。首次打开时，系统可能显示“未知发布者”，选择“更多信息”→“仍要运行”即可。

## 功能

- 按 `F8` 或点击按钮，框选屏幕价格并通过本地 OCR 自动识别
- 输入包含活动和满减券后的目标到手价，自动反算提报活动价与降幅
- 满减券无法触发时自动按无券价格计算
- OCR 完成后自动聚焦目标到手价输入框
- 窗口置顶和透明度调节
- 经典蓝、翡翠绿、暖阳橙、深邃黑四套皮肤
- 窗口自由缩放，文字和按钮随尺寸自适应
- 一键复制降幅

## 示例

当前价为 `60`，目标到手价为 `46`，优惠券为满 `50` 减 `5`：

- 需提报活动价：`51`
- 应填降幅：`15%`
- 券后到手价：`46`

## 隐私

屏幕截图和价格识别全部在电脑本地完成，不会上传商品信息或价格数据。

## 从源码构建

安装 Python 3.12 后，在 PowerShell 中运行：

```powershell
.\build.ps1
```

脚本会创建本地虚拟环境、安装依赖并生成单文件版 `activity-discount-helper.exe`。
